## Bugs fixed and evidence

- Per-color transmission distance survives compiler expansion and validation; 14 regression cases cover distinct/omitted values, invalid TD and COO, and weight/diameter combinations.
- Document links reject non-HTTP(S) URLs, and chart tooltips render text rather than interpolated HTML. Node and real-browser hostile-data checks cover these paths.
- Empty searches retain selected filters instead of silently resetting them; shared URLs restore filters; copied button labels retain their icon elements.
- Schema/Contributor overflow regions are keyboard-focusable. The schema fact-table header contrast was increased after axe reported a 4.12:1 failure.
- JSON download/export links use the same resource path as the loader, fixing 404s in `/public/` development previews. The browser test failed on the original download link and passed after correction.
